# 머신러닝 실패 사례 기반 분석 및 RAG 챗봇 프로젝트

## 1. 프로젝트 개요
이 프로젝트는 머신러닝 모델의 예측 실패 사례에 집중하여, 그 원인을 데이터 + LLM 기반 분석으로 해석하는 것이 목적입니다.

'왜 실패했는가'를 분석 대상으로 삼습니다.

## 2. 프로젝트의 의의
일반적으로 머신러닝은 모델의 성능을 높이는데에 집중하는 경우가 많습니다.
하지만 데이터 문제인지, 모델의 한계인지, 그리고 그 실패를 어떻게 해석해야 할지도 중요하다 생각합니다.
그러므로 이 프로젝트는 성능 높은 모델을 만들어 예측을 성공하는 것이 아닌 실패한 예측을 분석합니다.

## 3. 모델 선택 이유
실패 패턴이 명확히 드러나는 편인 로지스틱 회귀(Logistic Regression) 모델을 사용하였습니다.

## 4. 머신러닝
이 프로젝트에선 실패 분석을 위해 로지스틱 회귀를 사용하지만, 만약 높은 성능의 모델이 필요하다면 그리드 서치 등을 활용하여 교차 검증 기반 최적 모델 선택 구조로 확장 가능합니다.

## 5. 실패 사례
모델의 예측값이 실제 정답과 다른 경우입니다.

## 6. EDA 요약 및 LLM 활용
실패 사례를 요약하여 자연어 요약 텍스트를 생성합니다.
요약 텍스트는 사용자에게 실패 데이터 요약 정보를 전달함과 동시에 LLM을 위한 컨텍스트 역할을 수행합니다.

## 7. RAG(Retrieval-Augmented Generation) 구조
이 프로젝트는 실패 사례 데이터를 벡터화 하여 Vector DB에 저장합니다.
